# Adeptiq  (in progress)

## Developing an Adaptive Learning Platform for Personalized Education

LearnAdapt AI is an AI and ML powered adaptive learning platform designed to provide personalized education based on student performance.

## Main Features(in progress new features added soon)

- Class-based learning
- Self-learning mode
- AI quiz generation
- Teacher quiz management
- AI tutor
- AI-generated notes
- Handwritten-style notes
- Flashcards
- Personalized study plans
- ML-based mastery prediction
- Weak topic detection
- Adaptive difficulty
- Personalized recommendations
- Learning progress tracking
- Online educational resources
- Integrated learning view
